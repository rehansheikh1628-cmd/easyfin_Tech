Security & Architecture

Security & Data Privacy by Design

Financial documents require disciplined technical boundaries. CompactFin Tech operates under strict architectural protections:

Authenticated Workspace

Secure sessions with strict tenant boundaries isolate client files and conversion histories.

Protected Application Routes

Role and session-based guards protect converters, file records, and tenant workspaces.

Server-Side Validation

Every calculation, column layout, and checksum is verified deterministically on the server before export.

Untrusted XLSM Treated as Data

Uploaded macro-enabled spreadsheets are read strictly as passive tabular data streams.

No Macro Execution

No VBA scripts or embedded macros are ever executed on the server during Excel → Tally processing.
