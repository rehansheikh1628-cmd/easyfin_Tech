Processing Architecture

How EasyFin Statement Processing Works

A step-by-step breakdown of how raw PDF statements are parsed, verified, and mapped into structured Excel spreadsheets.

Engineering Transparency: Phase 1 vs Phase 2

You are viewing the Phase 1 UI & Foundation. The visual workflow and interactive review components shown below represent the exact user interface and pipeline. The core PDF extraction and machine bank detection engines are scheduled for Phase 2 integration.

1
Ingestion

1. Statement Upload & Header Parsing

Users upload raw bank statement PDFs (single page, multi-page, or password-protected files). EasyFin identifies the source bank, statement date range, opening balance, and account identifiers from document headers.

Input Formats PDF (Digital & Scanned)
Page Handling 1 to 500+ Pages
Header Metadata Account No, Period, Opening Balance
2
Extraction

2. Table Boundary Detection & Narration Joining

Bank statements frequently break descriptions across 2 to 4 lines. EasyFin's parsing engine aligns multi-line transaction narratives (UTR numbers, merchant codes, payer names) into cohesive single rows rather than fragmented records.

Multi-Line Handling Auto-concatenated narrations
Debit/Credit Detection Split columns or signed amounts
Date Normalization ISO & Local formats (DD/MM/YYYY)
3
Verification

3. Interactive Verification & Balance Reconciliation

Before any file is exported, accountants can inspect the transactions in a high-speed verification table. Running balance checks ensure that:
Opening Balance + Credits - Debits = Closing Balance. Any arithmetic discrepancies are highlighted instantly.

Audit Control In-browser transaction editor
Running Balance Check 100% mathematical match
Warning Flags Out-of-order dates or missing balances
4
Export

4. Clean Excel (.xlsx) & Accounting Export

Generate clean, formula-ready Microsoft Excel workbooks. Numbers are exported as real floating-point numbers (not strings masquerading as numbers), allowing immediate pivot tables, VLOOKUPs, and accounting imports.

File Types Microsoft Excel (.xlsx), CSV
Accounting Presets Standard Ledger, Tally XML format
Summary Sheet Monthly Debit/Credit breakdown
