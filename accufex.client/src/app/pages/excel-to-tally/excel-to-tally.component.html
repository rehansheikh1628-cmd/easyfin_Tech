Stage 02

How the Workflow Works

Follow these simple steps to ensure seamless validation and XML voucher generation.

  1. Download the official template (.xlsm).
  2. Open it in Microsoft Excel.
  3. Enter or paste your transactions into the Transactions sheet.
  4. Save the completed workbook.
  5. Upload it here for validation.
  6. Review validation checks and accounting ledger preview.
  7. Generate your Tally-compatible XML file.
Do not rename required columns.
Keep transaction data in the Transactions sheet.
Sample rows marked with [SAMPLE] are automatically ignored by the parser.
Canonical Columns (9):
1. Date (Req) 2. Narration 3. Cheque / Ref No. 4. Value Date 5. Dr Amount (Cond) 6. Cr Amount (Cond) 7. Closing Balance 8. Ledger Name (Req) 9. Bank Name (Req)

Next Step: Import into Tally

Download the generated XML file and import it into your Tally company using your normal Tally import workflow (Import Data → Vouchers).

• Debit amounts will create Payment vouchers.
• Credit amounts will create Receipt vouchers.
• Ensure the Ledger Name and Bank Name entered in your Excel sheet match existing ledgers in your Tally company chart of accounts.
