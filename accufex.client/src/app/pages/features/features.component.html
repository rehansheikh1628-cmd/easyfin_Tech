Technical Foundations

Engineered for Accounting Accuracy

Deterministic software engineering that validates every calculation.

Mathematical Balance Reconciliation

Verifies row-by-row arithmetic continuity across every extracted transaction:

Opening Balance + ΣCredits - ΣDebits = Closing Balance

Discrepancies are highlighted in the review grid for inspection rather than silenced.

Formula-Ready Excel Generation

Generated workbooks are built using ClosedXML directly into native OpenXML format (.xlsx).

  • True Numeric Floats: Formatted decimals (#,##0.00), never text strings.
  • Native Date Objects: Excel serial dates for immediate chronological filtering.
  • Preserved References: Alphanumeric UTR, NEFT, and cheque strings kept intact.

Auditable Review & Sidecar Storage

Inspect and edit transactions directly in the browser review table before export.

  • Pristine Original Snapshot: Raw extracted transactions remain immutable.
  • Sidecar Audit Trail: Corrections are tracked with original and updated values.
  • Live Re-validation: Edited balances immediately recalculate running checksums.

Multi-Client Workspace Repository

Manage statements systematically across clients, financial years, and processing states.

  • Multi-Dimensional Search: Filter by filename, client, or financial year.
  • Processing Metrics: Track Completed, Processing, and Flagged states.
  • Direct File Access: Download original PDF or export ClosedXML Excel anytime.

Factual Security & Ownership

Built with strict server-side authorization and private sandboxed file storage.

  • HTTP-Only Cookies: Authenticated sessions protected against script injection.
  • Tenant Authorization: Strict ownership verification from session to file.
  • Sandboxed Disk Storage: Statements stored outside public web roots.
